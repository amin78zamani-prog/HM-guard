# H.M guard: Federated Learning Security & Risk Analysis Framework

سامانه **H.M guard** یک پروژه تحقیقاتی در مقطع کارشناسی ارشد با هدف تحلیل ریسک‌ها، آسیب‌پذیری‌های امنیتی و حملات سایبری در بستر معماری **یادگیری فدرال (Federated Learning)** برای گره‌های لبه (Edge Devices) و شبکه‌های توزیع‌شده است.

## ویژگی‌های کلیدی پروژه
* **اسکنر محلی لینک:** تحلیل و دسته‌بندی امنیتی لینک‌ها در سه سطح **امن (Safe)**، **مشکوک (Suspicious)** و **ناامن (Unsafe)** به صورت کاملاً محلی روی دستگاه کاربر بدون افشای داده‌های خام.
* **شبیه‌سازی یادگیری فدرال:** تولید بردارهای وزن متناسب با نتایج تحلیل و ارسال پارامترها به سرور مرکزی.
* **مدل تهدید و حملات مسموم‌سازی:** ماژول اختصاصی برای شبیه‌سازی حملات **Model Poisoning** جهت ارزیابی مقاومت شبکه در برابر گره‌های مخرب.
* **سرور مرکزی هوشمند:** پیاده‌سازی مکانیزم‌های دفاعی و تشخیص ناهنجاری در سمت سرور (پایتون) برای ایزوله کردن به‌روزرسانی‌های مشکوک.

## ساختار پوشه‌ها
* `app/`: کدهای منبع اپلیکیشن اندروید (تحلیل‌گر لینک، مدیریت کلاینت فدرال و رابط کاربری).
* `server/`: کدهای سرور مرکزی پایتون جهت تجمیع مدل (FedAvg) و فیلتر کردن حملات.
* `docs/`: مستندات علمی، معماری و تحلیل ریسک پایان‌نامه.
