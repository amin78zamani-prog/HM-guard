# HM-guard
پروژه پایان‌نامه کارشناسی ارشد: تحلیل ریسک و امنیت در بستر یادگیری فدرال با تمرکز بر ارزیابی و دسته‌بندی امنیتی لینک‌ها در سیستم‌های لبه (Edge).

## قابلیت‌ها
* بررسی و تحلیل لینک‌ها در سه سطح: **امن (Safe)**، **مشکوک (Suspicious)**، و **ناامن (Unsafe)**.
* ساختار ماژولار برای توسعه به عنوان گره لبه در معماری یادگیری فدرال.
